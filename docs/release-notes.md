Download the app ZIP under **Assets**; you do not need the source code or Xcode.

- **AppleSilicon**: Macs with Apple M-series chips.
- **Intel**: Macs with Intel processors.
- Requires **macOS 14 or newer**.

Unzip the download, move **MyRagAI.app** into **Applications**, then open it.

These early builds are ad-hoc signed, not Developer ID signed or notarized by Apple. macOS may block the first launch. If you trust this download, use **System Settings → Privacy & Security → Open Anyway** after attempting to open it. Managed Macs may prevent this override.

The `.sha256` files let you verify each ZIP's checksum. GitHub's automatically generated “Source code” archives are for developers, not app installation.

AI answers require your own local model server or provider connection. No provider credentials or personal documents are included.
